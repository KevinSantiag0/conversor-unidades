# Unit Converter

Console tool that converts engineering units (temperature, voltage,
current, frequency) and keeps a timestamped history of every conversion.

## Features

- 7 conversions driven by a dictionary (adding one is a single line)
- Input validation: rejects non-numeric values and retries
- Persistent history saved to `history.txt`, viewable from the menu

## Requirements

Python 3.10 or newer. No external libraries.

## Usage

```bash
python3 conversor.py
```
